# LockedIn

Open `index.html` in any modern browser. The tracker keeps its information in that browser's local storage, so it remains after the page is closed and reopened on the same device/browser.

The checklist maps the action-oriented columns from the provided Job and Internship Search Guide: networking, application materials, follow-up/heard back, first interview, thank-you note, final interview, and final thank-you note. Application deadlines and interview dates appear in the calendar.
